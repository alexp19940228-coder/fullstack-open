# Full Stack Open

This repository contains my work as I study [Full Stack Open](https://fullstackopen.com/), a University of Helsinki course on modern web application development. The course teaches the tools and practices used to build full stack applications, starting with JavaScript and React and continuing into backend development and related topics.

## What I’m working toward

I’m working through the course one part at a time to build a solid understanding of full stack development by completing the exercises and applying what I learn in small projects. This folder is for Part 1, where I’m learning the fundamentals of React, including components, props, state, and handling events.

## Running this project

Install dependencies and start the development server:

```bash
npm install
npm run dev
```
