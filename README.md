# Full Stack Open

This repository contains my exercises and projects for [Full Stack Open](https://fullstackopen.com/), a free course from the University of Helsinki on modern web application development.

The course starts with JavaScript and React, then moves into building and testing backend services, working with databases, and developing full stack applications. It also covers topics such as TypeScript, GraphQL, containers, and continuous integration.

## Repository contents

- [`part1/`](part1/) — exercises and a React app from Part 1, covering React basics such as components, props, state, and event handling.

I’m working through the course part by part; more folders will be added as I progress.
